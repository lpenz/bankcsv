# bankcsv

`bankcsv` is a command-line tool that parses CSV files exported from bank/credit card statements and converts them to a GnuCash-compatible double-entry CSV format. By specifying account mapping rules using regular expressions in a JSON configuration file, `bankcsv` automatically categorizes transaction descriptions to their target GnuCash accounts.

## Features

- **Automatic Format Detection**: Automatically distinguishes between credit card CSVs and debit card/bank account CSVs.
- **Regex-based Categorization**: Map transaction descriptions to GnuCash accounts (e.g. `Expenses:Utilities:Electricity`) using regex.
- **Double-Entry Output**: Generates two lines per transaction (a source account split and a destination account split) to easily import into GnuCash without manual matching.
- **Completions and Manpages**: Ships with shell completions (Bash, Zsh, Fish) and a manual page.

## Installation

### Using Cargo

You can install `bankcsv` from crates.io:

```bash
cargo install bankcsv
```

### From Package Repositories

For Debian/Ubuntu or RPM-based distributions, precompiled packages are built in CI.

## Usage

```bash
bankcsv <source-account> <config-file> <inputs...> [OPTIONS]
```

### Arguments

- `<source-account>`: The default source GnuCash account for the imported transactions (e.g., `Liabilities:CreditCard` or `Assets:Checking`).
- `<config-file>`: Path to the JSON configuration file containing mapping rules.
- `<inputs...>`: One or more input CSV files exported from your bank.

### Options

- `-o, --output <output>`: Output CSV file path. Defaults to `-` (standard output).
- `-h, --help`: Prints help information.
- `-V, --version`: Prints version information.

### Examples

```bash
bankcsv Liabilities:CreditCard config.json statements/*.csv --output gnucash_import.csv
```

## Configuration File Format

The mapping rules are defined in a JSON file containing a list of matching rules under `"AccountFromDescription"`.

### Example `config.json`

```json
{
  "AccountFromDescription": [
    {
      "Account": "Expenses:Leisure:Entertainment",
      "Regex": "NETFLIX"
    },
    {
      "Account": "Expenses:Utilities:Electricity",
      "Regex": "POWER COMPANY .* INC"
    },
    {
      "Account": "Expenses:Food:Supermarket",
      "Regex": "(TESCO|ALDI|LIDL)"
    },
    {
      "Account": "Income:Salary",
      "Regex": "EMPLOYER CO CORP"
    }
  ]
}
```

Rules are evaluated sequentially. The first rule whose regular expression matches the transaction's description will assign that transaction to the specified account. If no rules match a transaction description, `bankcsv` will print a warning to `stderr` and skip the transaction.

## Supported Bank CSV Formats

`bankcsv` detects and handles two formats based on the header of the first column:

### 1. Credit Card Format
- **Trigger**: First column is `"Masked Card Number"`.
- **Columns used**:
  - **Date**: Column index 2 (`Processed` date, expected in `%d/%m/%Y` format).
  - **Description**: Column index 3.
  - **Amount / Value**: Column index 4 (`Paid out`) and 5 (`Paid in`).

### 2. Debit Card / Bank Account Format
- **Trigger**: First column is `"Posted Account"`.
- **Columns used**:
  - **Date**: Column index 1 (`Posted Transactions Date`, expected in `%d/%m/%Y` format).
  - **Description**: Column index 2 (`Description1`).
  - **Amount / Value**: Column index 5 (`Debit Amount`) and 6 (`Credit Amount`).

## Output CSV & GnuCash Import

The output format generated by `bankcsv` is structured with double-entry lines:

| id | date | description | amount | value | account |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `2026010901` | `2026-01-09` | `NETFLIX` | `9.95` | `9.95` | `Liabilities:CreditCard` |
| `2026010901` | `2026-01-09` | `NETFLIX` | `-9.95` | `-9.95` | `Expenses:Leisure:Entertainment` |

### How to Import into GnuCash

1. Open GnuCash.
2. Navigate to **File** -> **Import** -> **Import Transactions from CSV...**.
3. Select the output file generated by `bankcsv`.
4. In the Import settings:
   - Set **Format** to `Comma separated`.
   - Set **Multi-line Import (Split Transactions)** and select **Use Account Column**.
   - Map the CSV columns to the corresponding GnuCash fields:
     - Column 1: **Transaction ID**
     - Column 2: **Date**
     - Column 3: **Description**
     - Column 4: **Amount** (or Value)
     - Column 5: **Value** (or Amount)
     - Column 6: **Account**
5. Proceed and confirm the import.
